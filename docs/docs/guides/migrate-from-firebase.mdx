# Migrate from Firebase

This guide helps you migrate from Firebase/Firestore to FORGE with PostgreSQL.

## Overview

| Firebase | FORGE Equivalent |
|----------|------------------|
| Firestore | PostgreSQL |
| Cloud Functions | Jobs, Mutations, Workflows |
| Cloud Scheduler | Built-in cron |
| Realtime Database | PostgreSQL NOTIFY |
| Firebase Auth | Built-in JWT auth |

**Key difference:** Firebase uses NoSQL (documents), FORGE uses PostgreSQL (relational). This requires schema design.

## Step 1: Design Your PostgreSQL Schema

Convert Firestore collections to PostgreSQL tables.

**Firestore structure:**
```
users/
  {userId}/
    email: "user@example.com"
    name: "John"
    createdAt: timestamp
    orders/
      {orderId}/
        items: [...]
        total: 99.99
```

**PostgreSQL schema:**
```sql
-- migrations/0001_initial.sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email TEXT UNIQUE NOT NULL,
    name TEXT,
    created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE orders (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id),
    items JSONB NOT NULL,
    total DECIMAL(10,2) NOT NULL,
    created_at TIMESTAMPTZ DEFAULT now()
);

CREATE INDEX idx_orders_user_id ON orders(user_id);
```

## Step 2: Export Firestore Data

Use Firebase Admin SDK to export:

```javascript
// export-firestore.js
const admin = require('firebase-admin');
const fs = require('fs');

admin.initializeApp();
const db = admin.firestore();

async function exportCollection(name) {
  const snapshot = await db.collection(name).get();
  const data = snapshot.docs.map(doc => ({
    id: doc.id,
    ...doc.data()
  }));
  fs.writeFileSync(`${name}.json`, JSON.stringify(data, null, 2));
}

exportCollection('users');
exportCollection('orders');
```

## Step 5: Convert Firestore Queries

**Firebase:**
```javascript
// Get user's orders
const orders = await db.collection('users')
  .doc(userId)
  .collection('orders')
  .orderBy('createdAt', 'desc')
  .get();
```

**FORGE:**
```rust
#[forge::query]
pub async fn get_user_orders(ctx: &QueryContext, user_id: Uuid) -> Result<Vec<Order>> {
    // JOIN is free in PostgreSQL!
    sqlx::query_as!(Order, r#"
        SELECT o.*
        FROM orders o
        WHERE o.user_id = $1
        ORDER BY o.created_at DESC
    "#, user_id)
        .fetch_all(ctx.db())
        .await
        .map_err(Into::into)
}
```

## Step 6: Convert Cloud Functions

**Firebase Cloud Function:**
```javascript
exports.sendWelcomeEmail = functions.auth.user().onCreate(async (user) => {
  await sendEmail(user.email, 'Welcome!');
});

exports.processOrder = functions.firestore
  .document('orders/{orderId}')
  .onCreate(async (snap, context) => {
    const order = snap.data();
    await chargePayment(order);
    await createShipment(order);
  });
```

**FORGE equivalent:**
```rust
// Trigger job from mutation instead of Firestore trigger
#[forge::mutation]
pub async fn create_user(ctx: &MutationContext, input: CreateUserInput) -> Result<User> {
    let user = create_user_in_db(ctx.db(), &input).await?;

    // Dispatch welcome email job
    ctx.dispatch_job("send_welcome_email", json!({
        "email": user.email,
        "name": user.name,
    })).await?;

    Ok(user)
}

#[forge::job]
pub async fn send_welcome_email(ctx: &JobContext, input: EmailInput) -> Result<()> {
    send_email(&input.email, "Welcome!").await
}

// Use workflow for multi-step order processing
#[forge::workflow]
pub async fn process_order(ctx: &WorkflowContext, input: OrderInput) -> Result<()> {
    ctx.step("charge_payment")
        .run(|| charge_payment(&input))
        .compensate(|p| refund(&p.id))
        .await?;

    ctx.step("create_shipment")
        .run(|| create_shipment(&input))
        .await?;

    Ok(())
}
```

## Step 7: Convert Scheduled Functions

**Firebase Cloud Scheduler:**
```javascript
exports.dailyCleanup = functions.pubsub
  .schedule('0 3 * * *')
  .onRun(async (context) => {
    await cleanupOldData();
  });
```

**FORGE Cron:**
```rust
#[forge::cron("0 3 * * *")]
pub async fn daily_cleanup(ctx: &CronContext) -> Result<()> {
    cleanup_old_data(ctx.db()).await
}
```

## Step 8: Convert Realtime

**Firebase Realtime:**
```javascript
// Listen to changes
db.collection('messages')
  .where('roomId', '==', roomId)
  .onSnapshot((snapshot) => {
    snapshot.docChanges().forEach((change) => {
      if (change.type === 'added') {
        displayMessage(change.doc.data());
      }
    });
  });
```

**FORGE:**
```rust
// Server: Broadcast on mutation
#[forge::mutation]
pub async fn send_message(ctx: &MutationContext, input: MessageInput) -> Result<Message> {
    let message = create_message(ctx.db(), &input).await?;

    ctx.broadcast(&format!("room:{}", input.room_id), &message).await?;

    Ok(message)
}
```

```typescript
// Client: Subscribe
forge.subscribe(`room:${roomId}`, (message) => {
  displayMessage(message);
});
```

## Step 9: Import Data

Create an import script:

```rust
// scripts/import.rs
use std::fs;
use serde_json::Value;

async fn import_users(db: &PgPool) -> Result<()> {
    let data: Vec<Value> = serde_json::from_str(
        &fs::read_to_string("users.json")?
    )?;

    for user in data {
        sqlx::query(r#"
            INSERT INTO users (id, email, name, created_at)
            VALUES ($1, $2, $3, $4)
            ON CONFLICT (id) DO NOTHING
        "#)
            .bind(Uuid::parse_str(user["id"].as_str().unwrap())?)
            .bind(user["email"].as_str())
            .bind(user["name"].as_str())
            .bind(/* parse timestamp */)
            .execute(db)
            .await?;
    }

    Ok(())
}
```

## Step 10: Auth Migration

### Option A: Keep Firebase Auth
FORGE can validate Firebase JWTs:

```toml
# forge.toml
[auth]
provider = "firebase"
project_id = "your-firebase-project"
```

### Option B: Migrate Users
1. Export Firebase users with Firebase Admin SDK
2. Import into PostgreSQL users table
3. Implement password reset flow (Firebase hashes aren't exportable)

```javascript
// Export Firebase Auth users
const admin = require('firebase-admin');
const auth = admin.auth();

async function exportUsers() {
  const users = [];
  let nextPageToken;

  do {
    const result = await auth.listUsers(1000, nextPageToken);
    users.push(...result.users.map(u => ({
      uid: u.uid,
      email: u.email,
      displayName: u.displayName,
      createdAt: u.metadata.creationTime,
    })));
    nextPageToken = result.pageToken;
  } while (nextPageToken);

  return users;
}
```

## Frontend Migration

**Before (Firebase):**
```javascript
import { initializeApp } from 'firebase/app';
import { getFirestore, collection, getDocs } from 'firebase/firestore';

const app = initializeApp(config);
const db = getFirestore(app);

const users = await getDocs(collection(db, 'users'));
```

**After (FORGE):**
```typescript
import { createForgeClient } from '$lib/forge';

const forge = createForgeClient({ baseUrl: 'http://localhost:8080' });

const users = await forge.query('list_users', {});
```

## Key Differences to Remember

| Firebase | FORGE |
|----------|-------|
| Document triggers | Explicit job dispatch in mutations |
| Subcollections | Foreign keys with JOINs |
| Compound queries limited | Full SQL power |
| Automatic scaling | Manual scaling (but predictable cost) |
| Vendor lock-in | Run anywhere |
