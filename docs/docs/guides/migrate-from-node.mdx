# Migrate from Express/Node.js

This guide helps you migrate from Express, Fastify, or other Node.js backends to FORGE.

## Overview

| Node.js Stack | FORGE Equivalent |
|---------------|------------------|
| Express routes | Query/Mutation functions |
| Bull/BullMQ | Built-in jobs |
| node-cron | Built-in cron |
| Socket.io | PostgreSQL NOTIFY |
| Prisma/Sequelize | sqlx |

## Step 1: Map Your Routes

**Express:**
```javascript
// routes/users.js
app.get('/users/:id', async (req, res) => {
  const user = await db.user.findUnique({ where: { id: req.params.id } });
  res.json(user);
});

app.post('/users', async (req, res) => {
  const user = await db.user.create({ data: req.body });
  await emailQueue.add('welcome', { email: user.email });
  res.json(user);
});
```

**FORGE:**
```rust
#[forge::query]
pub async fn get_user(ctx: &QueryContext, id: Uuid) -> Result<User> {
    sqlx::query_as!(User, "SELECT * FROM users WHERE id = $1", id)
        .fetch_optional(ctx.db())
        .await?
        .ok_or(ForgeError::NotFound("User not found".into()))
}

#[forge::mutation]
pub async fn create_user(ctx: &MutationContext, input: CreateUserInput) -> Result<User> {
    let user = sqlx::query_as!(User, r#"
        INSERT INTO users (email, name) VALUES ($1, $2) RETURNING *
    "#, input.email, input.name)
        .fetch_one(ctx.db())
        .await?;

    ctx.dispatch_job("send_welcome_email", json!({ "email": user.email })).await?;

    Ok(user)
}
```

## Step 2: Convert Job Queues

**Bull/BullMQ:**
```javascript
// jobs/emailQueue.js
const emailQueue = new Queue('email');

emailQueue.process('welcome', async (job) => {
  await sendEmail(job.data.email, 'Welcome!');
});

// Usage
await emailQueue.add('welcome', { email: 'user@example.com' });
```

**FORGE:**
```rust
#[forge::job]
#[retry(max_attempts = 3)]
pub async fn send_welcome_email(ctx: &JobContext, input: EmailInput) -> Result<()> {
    ctx.progress(0, "Sending...")?;
    send_email(&input.email, "Welcome!").await?;
    ctx.progress(100, "Sent")?;
    Ok(())
}

// Usage (in mutation)
ctx.dispatch_job("send_welcome_email", json!({ "email": "user@example.com" })).await?;
```

## Step 3: Convert Cron Jobs

**node-cron:**
```javascript
const cron = require('node-cron');

cron.schedule('0 3 * * *', async () => {
  await cleanupOldRecords();
});
```

**FORGE:**
```rust
#[forge::cron("0 3 * * *")]
pub async fn cleanup_old_records(ctx: &CronContext) -> Result<()> {
    sqlx::query("DELETE FROM temp_data WHERE created_at < now() - interval '7 days'")
        .execute(ctx.db())
        .await?;
    Ok(())
}
```

## Step 4: Convert WebSockets

**Socket.io:**
```javascript
io.on('connection', (socket) => {
  socket.on('join-room', (roomId) => {
    socket.join(roomId);
  });

  socket.on('message', (data) => {
    io.to(data.roomId).emit('message', data);
  });
});
```

**FORGE:**
```rust
#[forge::mutation]
pub async fn send_message(ctx: &MutationContext, input: MessageInput) -> Result<Message> {
    let message = create_message(ctx.db(), &input).await?;

    // Broadcast to room subscribers
    ctx.broadcast(&format!("room:{}", input.room_id), &message).await?;

    Ok(message)
}
```

```typescript
// Frontend
forge.subscribe(`room:${roomId}`, (message) => {
  displayMessage(message);
});
```

## Step 5: Convert Middleware

**Express middleware:**
```javascript
// Auth middleware
app.use(async (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) return res.status(401).json({ error: 'Unauthorized' });

  try {
    req.user = jwt.verify(token, process.env.JWT_SECRET);
    next();
  } catch {
    res.status(401).json({ error: 'Invalid token' });
  }
});
```

**FORGE (built-in):**
```rust
#[forge::query]
pub async fn get_profile(ctx: &QueryContext) -> Result<User> {
    // Auth is automatic - just require user
    let user_id = ctx.require_user_id()?;

    sqlx::query_as!(User, "SELECT * FROM users WHERE id = $1", user_id)
        .fetch_one(ctx.db())
        .await
        .map_err(Into::into)
}
```

## Step 6: Convert Database Queries

**Prisma:**
```javascript
const user = await prisma.user.findUnique({
  where: { id },
  include: { orders: true }
});
```

**FORGE (sqlx):**
```rust
#[forge::query]
pub async fn get_user_with_orders(ctx: &QueryContext, id: Uuid) -> Result<UserWithOrders> {
    let user = sqlx::query_as!(User, "SELECT * FROM users WHERE id = $1", id)
        .fetch_one(ctx.db())
        .await?;

    let orders = sqlx::query_as!(Order, "SELECT * FROM orders WHERE user_id = $1", id)
        .fetch_all(ctx.db())
        .await?;

    Ok(UserWithOrders { user, orders })
}
```

Or use a single query with JOIN:
```rust
#[derive(sqlx::FromRow)]
pub struct UserOrderRow {
    user_id: Uuid,
    user_email: String,
    order_id: Option<Uuid>,
    order_total: Option<f64>,
}

let rows = sqlx::query_as!(UserOrderRow, r#"
    SELECT u.id as user_id, u.email as user_email,
           o.id as order_id, o.total as order_total
    FROM users u
    LEFT JOIN orders o ON o.user_id = u.id
    WHERE u.id = $1
"#, id)
    .fetch_all(ctx.db())
    .await?;
```

## Step 7: Convert Webhooks

**Express:**
```javascript
app.post('/webhooks/stripe', async (req, res) => {
  const event = req.body;
  if (event.type === 'checkout.session.completed') {
    await fulfillOrder(event.data.object);
  }
  res.json({ received: true });
});
```

**FORGE:**
```rust
#[forge::action]
pub async fn stripe_webhook(ctx: &ActionContext, event: StripeEvent) -> Result<()> {
    if event.type_ == "checkout.session.completed" {
        ctx.dispatch_workflow("fulfill_order", event.data).await?;
    }
    Ok(())
}
```

## Type Safety Benefits

**Before (JavaScript):**
```javascript
// Runtime error if user is undefined
const email = user.email;

// Typo not caught until runtime
const oder = await createOrder(data);
```

**After (Rust):**
```rust
// Compile error if user might be None
let email = user.email;  // Compiler ensures user exists

// Typo caught at compile time
let oder = create_order(&data).await;  // Error: `oder` never used
```

## Performance Comparison

| Metric | Node.js | FORGE |
|--------|---------|-------|
| Cold start | ~100-500ms | ~10ms |
| Memory/request | ~50MB | ~5MB |
| Throughput | ~10K req/s | ~50K req/s |
| Type checking | Runtime | Compile-time |
