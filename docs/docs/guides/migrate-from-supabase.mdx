# Migrate from Supabase

This guide helps you migrate from Supabase to FORGE while keeping your PostgreSQL data.

## Overview

| Supabase | FORGE Equivalent |
|----------|------------------|
| PostgREST (auto-API) | Rust query/mutation functions |
| Edge Functions (Deno) | Jobs, Mutations, Workflows |
| pg_cron | Built-in cron |
| Realtime | PostgreSQL NOTIFY subscriptions |
| Auth | Built-in JWT auth |

## Step 1: Export Your Schema

```bash
# From Supabase dashboard or CLI
supabase db dump --schema public > schema.sql
```

Or use pg_dump:
```bash
pg_dump --schema-only --no-owner -d YOUR_SUPABASE_DB > schema.sql
```

## Step 2: Create FORGE Project

```bash
forge new my-app
cd my-app
```

## Step 3: Create Rust Models

Convert your tables to Rust structs.

**Supabase table:**
```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  name TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

**FORGE model:**
```rust
// src/schema/user.rs
use forge::prelude::*;

#[derive(Debug, Clone, Serialize, Deserialize, sqlx::FromRow)]
pub struct User {
    pub id: Uuid,
    pub email: String,
    pub name: Option<String>,
    pub created_at: DateTime<Utc>,
}

// Input for creating users
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CreateUserInput {
    pub email: String,
    pub name: Option<String>,
}
```

## Step 4: Convert PostgREST Queries

**Supabase (client-side):**
```javascript
// Get user
const { data } = await supabase
  .from('users')
  .select('*')
  .eq('id', userId)
  .single();

// Create user
const { data } = await supabase
  .from('users')
  .insert({ email, name })
  .select()
  .single();
```

**FORGE (server-side):**
```rust
// src/functions/users.rs
use forge::prelude::*;

#[forge::query]
pub async fn get_user(ctx: &QueryContext, id: Uuid) -> Result<User> {
    sqlx::query_as!(User, "SELECT * FROM users WHERE id = $1", id)
        .fetch_optional(ctx.db())
        .await?
        .ok_or(ForgeError::NotFound("User not found".into()))
}

#[forge::mutation]
pub async fn create_user(ctx: &MutationContext, input: CreateUserInput) -> Result<User> {
    sqlx::query_as!(User, r#"
        INSERT INTO users (email, name)
        VALUES ($1, $2)
        RETURNING *
    "#, input.email, input.name)
        .fetch_one(ctx.db())
        .await
        .map_err(Into::into)
}
```

**New frontend (TypeScript):**
```typescript
// After running `forge generate`
import { forge } from '$lib/forge';

const user = await forge.query('get_user', { id: userId });
const newUser = await forge.mutation('create_user', { email, name });
```

## Step 5: Convert Edge Functions

**Supabase Edge Function:**
```typescript
// supabase/functions/send-email/index.ts
import { serve } from 'https://deno.land/std/http/server.ts';

serve(async (req) => {
  const { email, subject, body } = await req.json();

  await fetch('https://api.sendgrid.com/v3/mail/send', {
    method: 'POST',
    headers: { Authorization: `Bearer ${Deno.env.get('SENDGRID_KEY')}` },
    body: JSON.stringify({ to: email, subject, content: body }),
  });

  return new Response(JSON.stringify({ success: true }));
});
```

**FORGE Job:**
```rust
// src/functions/send_email_job.rs
use forge::prelude::*;

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SendEmailInput {
    pub email: String,
    pub subject: String,
    pub body: String,
}

#[forge::job]
#[retry(max_attempts = 3)]
pub async fn send_email(ctx: &JobContext, input: SendEmailInput) -> Result<()> {
    ctx.progress(0, "Sending email...")?;

    ctx.http()
        .post("https://api.sendgrid.com/v3/mail/send")
        .bearer_auth(&std::env::var("SENDGRID_KEY")?)
        .json(&serde_json::json!({
            "personalizations": [{ "to": [{ "email": input.email }] }],
            "from": { "email": "noreply@yourdomain.com" },
            "subject": input.subject,
            "content": [{ "type": "text/plain", "value": input.body }]
        }))
        .send()
        .await?;

    ctx.progress(100, "Email sent")?;
    Ok(())
}
```

## Step 6: Convert Webhooks to Mutations

**Supabase webhook handler:**
```typescript
// Edge Function handling Stripe webhooks
serve(async (req) => {
  const event = await req.json();
  if (event.type === 'checkout.session.completed') {
    // Handle payment
  }
  return new Response('ok');
});
```

**FORGE Mutation:**
```rust
#[forge::mutation]
pub async fn stripe_webhook(ctx: &MutationContext, event: StripeEvent) -> Result<()> {
    match event.type_.as_str() {
        "checkout.session.completed" => {
            ctx.dispatch_job("fulfill_order", event.data).await?;
        }
        _ => {}
    }
    Ok(())
}
```

## Step 7: Convert pg_cron

**Supabase pg_cron:**
```sql
SELECT cron.schedule(
  'cleanup-old-data',
  '0 3 * * *',
  $$DELETE FROM temp_data WHERE created_at < now() - interval '7 days'$$
);
```

**FORGE Cron:**
```rust
#[forge::cron("0 3 * * *")]
pub async fn cleanup_old_data(ctx: &CronContext) -> Result<()> {
    sqlx::query("DELETE FROM temp_data WHERE created_at < now() - interval '7 days'")
        .execute(ctx.db())
        .await?;
    Ok(())
}
```

## Step 8: Convert Realtime

**Supabase Realtime:**
```javascript
const channel = supabase
  .channel('posts')
  .on('postgres_changes',
    { event: 'INSERT', schema: 'public', table: 'posts' },
    (payload) => console.log('New post:', payload)
  )
  .subscribe();
```

**FORGE (server broadcast):**
```rust
#[forge::mutation]
pub async fn create_post(ctx: &MutationContext, input: PostInput) -> Result<Post> {
    let post = create_post_in_db(ctx.db(), &input).await?;

    // Broadcast to subscribers
    ctx.broadcast("posts:created", &post).await?;

    Ok(post)
}
```

**FORGE (client subscribe):**
```typescript
forge.subscribe('posts:created', (post) => {
  console.log('New post:', post);
});
```

## Step 9: Migrate Data

Your PostgreSQL data stays in PostgreSQL! Just update the connection string.

```bash
# Export from Supabase
pg_dump -d YOUR_SUPABASE_DB > data.sql

# Import to new database
psql -d YOUR_NEW_DB < data.sql
```

## Step 10: Update Frontend Client

Replace the Supabase client with FORGE client:

```typescript
// Before (Supabase)
import { createClient } from '@supabase/supabase-js';
const supabase = createClient(url, key);

// After (FORGE)
import { createForgeClient } from '$lib/forge';
const forge = createForgeClient({
  baseUrl: 'http://localhost:8080',
});
```

## Auth Migration

If you're using Supabase Auth, you have options:

### Option A: Keep Supabase Auth
FORGE can validate Supabase JWTs. Configure in `forge.toml`:
```toml
[auth]
jwt_secret = "your-supabase-jwt-secret"
```

### Option B: Migrate to FORGE Auth
Export users and implement password reset flow for migration.
