# Quick Start

Let's build a working FORGE app in 5 minutes. By the end, you'll have a full-stack app with a database, API, and reactive frontend.

## Prerequisites

Before starting, make sure you have:

- **Rust** (1.92+) - [Install Rust](https://rustup.rs/)
- **Bun** (1.3.1+) - [Install Bun](https://bun.sh/)
- **Docker** - For running PostgreSQL locally
- **PostgreSQL client** (optional) - For database inspection

```bash
# Check your versions
rustc --version  # Should be 1.92+
bun --version    # Should be 1.3.1+
docker --version
```

## Step 1: Install FORGE CLI

```bash
# Quick install (recommended)
curl -fsSL https://tryforge.dev/install.sh | sh

# Or build from source with embedded PostgreSQL support
git clone https://github.com/isala404/forge.git
cd forge
cargo install --path crates/forge --features embedded-db
```

Verify it works:

```bash
forge --version
```

## Step 2: Create Your Project

```bash
# Create a new FORGE project with demo examples
forge new my-app --demo
cd my-app
```

:::tip Starting from scratch?
Use `forge new my-app --minimal` for clean scaffolding without example code. This is useful when you're experienced with FORGE and want to build from scratch rather than modify the demo app.
:::

This creates a complete project structure:

```
my-app/
├── Cargo.toml           # Rust dependencies
├── forge.toml           # FORGE configuration
├── .env                 # Environment variables
├── migrations/          # SQL migrations
│   └── 0001_initial.sql
├── src/
│   ├── main.rs          # Entry point
│   ├── schema/          # Data models
│   └── functions/       # Your API functions
└── frontend/            # Svelte 5 app
    ├── package.json
    └── src/
```

## Step 3: Start Development

```bash
forge dev
```

That's it! This single command:

1. **Starts embedded PostgreSQL** (data stored in `./pg_data/`)
2. **Compiles your backend** and runs migrations
3. **Starts the backend** with hot reload via cargo-watch
4. **Installs frontend dependencies** and starts the dev server
5. **Opens your browser** automatically

You should see:

```
🚀 Starting FORGE development environment...

  ✓ cargo found
  ✓ bun found

  ⋯ Starting embedded PostgreSQL...
  ✓ Embedded PostgreSQL running on port 5433
    → Data: ./pg_data/

  ⋯ Compiling backend...
  ✓ Backend compiled successfully

  → Backend: http://localhost:8080
  → Dashboard: http://localhost:8080/_dashboard
  → Frontend: http://localhost:5173

✅ Development server running. Press Ctrl+C to stop.
```

## Step 4: Explore

- **App**: http://localhost:5173 - Your Svelte frontend
- **Dashboard**: http://localhost:8080/_dashboard - Admin panel
- **API**: http://localhost:8080/rpc - Backend endpoints

The dashboard shows:
- **Cluster health** - Node status
- **Jobs** - Background job queue
- **Logs** - Real-time logs
- **Metrics** - Request counts, latency

## What Just Happened?

You now have:

1. **An embedded PostgreSQL database** with your schema
2. **A Rust backend** with auto-generated API endpoints
3. **A Svelte frontend** with reactive data fetching
4. **Real-time updates** via WebSocket
5. **An admin dashboard** for monitoring

All from two commands: `forge new --demo` and `forge dev`.

## Your First Change

Let's add a simple feature. Open `src/functions/users.rs`:

```rust
use forge::prelude::*;

#[derive(Debug, Serialize, Deserialize, sqlx::FromRow)]
pub struct User {
    pub id: Uuid,
    pub email: String,
    pub name: String,
    pub created_at: DateTime<Utc>,
}

#[forge::query]
pub async fn list_users(ctx: &QueryContext) -> Result<Vec<User>> {
    sqlx::query_as("SELECT * FROM users ORDER BY created_at DESC")
        .fetch_all(ctx.db())
        .await
        .map_err(Into::into)
}
```

The frontend can now use this query:

```svelte
<script>
  import { subscribe } from '$lib/forge';

  const users = subscribe('list_users', {});
</script>

{#if $users.loading}
  <p>Loading...</p>
{:else}
  {#each $users.data ?? [] as user}
    <p>{user.name} ({user.email})</p>
  {/each}
{/if}
```

**Changes sync automatically!** When you add a user, the list updates in real-time.

## Alternative: Docker Compose

If you prefer containerized development:

```bash
docker compose up --build
```

This starts PostgreSQL, backend with hot reload, and frontend - all containerized.

## Using an External Database

If you prefer using your own PostgreSQL instance:

```bash
# Set your database URL
echo "DATABASE_URL=postgres://user:pass@localhost:5432/myapp" >> .env

# Start without embedded postgres
forge dev --no-pg
```

## Troubleshooting

### "cargo: command not found"

Install Rust: https://rustup.rs/

### "bun: command not found"

Install Bun: https://bun.sh/

### "No DATABASE_URL set and embedded PostgreSQL not available"

You need to either:
1. Install forge with embedded-db feature: `cargo install forgex --features embedded-db`
2. Or set a DATABASE_URL in your `.env` file and use `forge dev --no-pg`

### Port already in use

Change the port in `forge.toml`:
```toml
[gateway]
port = 8081
```

Or use the command line flag:
```bash
forge dev --port 8081
```
